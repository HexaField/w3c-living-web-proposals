The Specifications

Ten W3C-format draft specifications, arranged so each depends only on the ones above it.

#SpecificationDescription
01 Decentralised Identity Extends navigator.credentials with did:key and did:graph
02 Personal Linked-Data Graphs navigator.graph — GraphStore + Context + SPARQL 1.2 + RDF 1.2 reifiers
03 Decentralised Group Identity did:graph + DID-document-as-triples + groupification; substrate dependency for the capability framework
04 Graph Capability Framework Scope-set governance (hierarchical + holonic); accumulate + deny-wins; BootstrapRoot chain-cut; immutable-caveats attenuation; Open / Announced / Enforced
05 Context Sync Protocol GraphDiff + sync spaces + per-graph subscription; sync-blocking respects the full scope-set governance
06 Sync Module Architecture Pluggable WASM module interface, capability sandbox, lifecycle, user consent
07 Dynamic Graph Shape Validation SHACL extension with constructors, setters, collections, cross-graph inheritance
08 Governance Constraint Vocabulary Standard constraint kinds: temporal, content, credential, shape — plugged into the capability framework
09 Default Sync Module Built-in OR-Set CRDT module with WebTransport relay protocol, NAT traversal, snapshot promotion
10 Graph Flows Declarative state machines with SPARQL ASK guards, temporal constraints, and role requirements
